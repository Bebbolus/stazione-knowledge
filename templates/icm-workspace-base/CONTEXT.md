# Contesto del Progetto

Questo file inquadra il problema operativo che il progetto mira a risolvere. Scrivi qui gli obiettivi di alto livello, le dipendenze fondamentali e i criteri di successo. L'agente leggerà questo documento all'avvio della sessione per orientarsi all'interno della struttura logica del lavoro, senza doversi affidare a conversazioni di chat precedenti.
