# Fase 1: Ricerca e Raccolta Dati

Questa cartella rappresenta il primo stadio logico del flusso di lavoro sequenziale. Ogni file inserito qui deve contenere dati grezzi, estratti da fonti esterne tramite operazioni di scraping o letture di database. L'agente incaricato di operare in questo stadio non deve produrre analisi, ma limitarsi a preparare il materiale per il passaggio di consegne allo stadio successivo.
