# Stazione – Knowledge Base AI / OSINT

Questo repository raccoglie le lezioni, gli appunti e i materiali
del mio percorso di studio su:

- Intelligenza Artificiale e modelli di linguaggio
- Sistemi agentici e orchestrazione
- OSINT e metodologie di intelligence
- Second brain, wiki-LLM e gestione della conoscenza

L'obiettivo è avere una base di conoscenza:

- leggibile da qualunque dispositivo (desktop, mobile)
- versionata via Git e GitHub
- riutilizzabile in futuro come curriculum / corso per altri

Il contenuto è principalmente in italiano, con occasionali riferimenti
a risorse internazionali (paper, documentazione, corsi).
